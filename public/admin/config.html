Planos de sala

Un local puede tener varios planos (p. ej. uno estándar y otro para eventos con la terraza reorganizada). Cambiar qué plano aplica un día — incluso uno que ya tiene reservas — nunca modifica esas reservas: solo cambia qué mesas se ofrecen para reservas nuevas a partir de ese momento.

Combinaciones de mesas

Selecciona 2 o más mesas de este plano que se puedan unir para grupos grandes. El aforo mín./máx. es opcional: si lo dejas en blanco, se calcula sumando el máximo de cada mesa; si lo indicas (como en Cover), manda ese número aunque no coincida con la suma.

Agenda: qué plano aplica cada día

Por defecto se usa el plano marcado "por defecto". Aquí puedes forzar un plano distinto para un día concreto (p. ej. un evento), sin tocar ningún otro día.

Nuevo plano

Si eliges un plano existente, se copian sus zonas, mesas y combinaciones como punto de partida (puedes editarlas después sin afectar al plano original).
